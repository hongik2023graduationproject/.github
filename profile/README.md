# hong-ik 한글 프로그래밍 언어

홍익대학교 2023 졸업 프로젝트로 시작한, 한국어 키워드로 코드를 쓰는 프로그래밍 언어입니다.

```
함수 인사(문자 이름) -> 문자:
    리턴 "안녕하세요, {이름}님!"

출력(인사("세계"))
```

**[hongik.tolelom.xyz](https://hongik.tolelom.xyz)** — 설치 없이 브라우저에서 바로 실행해 보세요 ([플레이그라운드](https://hongik.tolelom.xyz/playground/) · [문서](https://hongik.tolelom.xyz/docs/))
